# Summary
KENRYU is an open-source platform for the convergent analysis of microRNA (miRNA) target genes. Given a panel of miRNAs, it identifies the genes regulated by all — or nearly all — of them, combining thermodynamic target predictions from TargetScanHuman v8.0 [@lewis2005conserved; @mcgeary2019targeting], served locally, with post-hoc validation of each convergent gene against experimentally validated interactions from miRTarBase [@huang2022mirtarbase] and clinical databases (also a fallback when TargetScan has no data for a miRNA). Three consensus modes (Strict, N-1, N-2) let the user trade sensitivity against confidence. Each convergent gene is then annotated with local functional enrichment (KEGG, Reactome, WikiPathways, GO Biological Process), a live Enrichr [@kuleshov2016enrichr] cross-check, and parallel evidence from PubMed, OMIM, ClinVar and ClinicalTrials.gov [@sayers2022ncbi]. Results are shown as Venn diagrams, volcano plots, and a protein–protein interactome, and exported as a paginated academic report with a Vancouver-style bibliography. KENRYU is a FastAPI service with a web interface, containerized with Docker and deployed on Hugging Face Spaces, with a local database of 285 miRNA families and 13,035 human target genes. It is research-use-only software: it generates hypotheses and organizes evidence, and it does not provide clinical or diagnostic recommendations.

# Statement of need
miRNA target analysis is fragmented in practice: prediction and experimental validation live in separate tools, enrichment in another, and literature and clinical-trial evidence in yet others. A researcher studying a miRNA panel must therefore stitch together several resources by hand to answer one question — which genes does this panel converge on, and what is known about them? Existing tools typically export tables or isolated visualizations, or sum predictions from many predictors. KENRYU instead builds its consensus on TargetScan predictions and checks each convergent gene against miRTarBase and clinical databases in a validation dossier, then integrates enrichment, literature, and clinical-trial evidence into a single report, so every gene arrives with its evidence attached, showing which have experimental support and which are prediction-only.

# State of the field
Several established tools cover parts of this workflow; none covers the whole panel-to-report path. multiMiR [@ru2014multimir], a Bioconductor R package, has no web interface, no consensus modes and no report generation.

| Tool | Input | Core computation | Evidence per gene | Runs where |
|---|---|---|---|---|
| miRPathDB 2027 [@flotho2026mirpathdb] | one miRNA or one pathway | precomputed miRNA–pathway associations; 3 cumulative evidence tiers; 4 species | tier per association | web database |
| miRNet [@fan2016mirnet] | miRNA/gene list | 11 miRNA databases; network visualisation + functional analysis | network edges | web only |
| miRWalk 3.0 [@sticht2018mirwalk] | miRNA/gene | TarPmiR binding-site scan + TargetScan/miRDB/miRTarBase | target lists | web form |
| DIANA-miRPath v4.0 [@tastsoglou2023mirpath] | miRNA list | target union/intersection; one-sided Fisher exact test; experimental + predicted interactions | pathway level | web |
| miEAA 2023 [@aparicio2023mieaa] | miRNA list (10 species) | enrichment over 139,399 miRNA sets (19 repositories); API + package | miRNA-set membership | web / API / package |
| **KENRYU** | **miRNA panel** | **TargetScan convergence + miRTarBase tiers (inherited) + per-gene dossier + calibrated enrichment + bilingual report** | **strong/weak/none per gene, with PMIDs** | **local/offline or hosted** |

Existing tools cover intersection, evidence by levels and target enrichment; KENRYU contributes a reproducible offline flow, with documented calibration against random lists and panels, and documentation in Spanish. Its strong/weak split is miRTarBase's own classification, inherited, not a contribution. The full comparison, with sources, is in `docs/comparison.md`.

# Validation and use
KENRYU was validated on a five-miRNA lipid panel (hsa-miR-33a-5p, hsa-miR-33b-5p, hsa-miR-144-3p, hsa-miR-758-3p, hsa-miR-106b-5p), recovering the known miR-33 → ABCA1 axis and returning five convergent genes — ABCA1, KPNA3, SCN1A, SNTB2, TSC22D2. The five names are four independent seed families (miR-33a and miR-33b share one), and the count itself is not unusual: against 10,000 random size-matched family panels the empirical p is 0.14 for the lipid panel and 0.10 for the cancer panel — the evidence is in the per-gene dossier, not in the count. The report shows the same test live: 2,000 random size-matched panels per tolerance (±10–50%), the p as a range with its resolution, and the effective size with a warning when miRNAs share a family. This analysis is part of the author's master's thesis (Universidad Internacional de La Rioja, 2026). A second, independent case study used a cancer panel never tried before (hsa-miR-21-5p, hsa-miR-155-5p, hsa-let-7a-5p): the deployed service, in Strict mode, returned 18 convergent genes (listed in `docs/case-study-cancer-panel.md`) with three exploratory Enrichr terms (Developmental Biology, Reactome, p-adj 0.0176; Recycling Pathway of L1, 0.0424; Signaling by TGFBR3, 0.0424).

The enrichment method is the calibrated local Fisher test with the TargetScan universe as background, not the live Enrichr route. A random-panel protocol (`validate_random_panels.py`; 665 panels; seeds 7, 11, 3) measures the false-positive rate — the share of random panels with at least one term at adjusted p < 0.05. With the TargetScan universe the local rate is above 5% for larger lists (miRNA targets concentrate in regulatory genes) and near zero for thesis-sized panels (rates in `docs/validation/`). The same protocol against the live Enrichr route (`calibrate_enrichr.py`; 100 random lists, four libraries, checked 2026-11-19) gives a false-positive rate of 98% (GO), 75% (Reactome), 86% (WikiPathways) and 56% (KEGG) for 5-gene lists and 30%, 18%, 19% and 10% for 18-gene lists (51% with at least one term in any library). For 100-gene lists (30 lists) the rate falls to 10%, 3%, 17% and 23% per library (37% in any library, against ≈18.5% expected under calibration) — lower, but GO and Reactome are the only libraries whose intervals include 5%, so no size threshold can be claimed from these data. Single-gene overlaps already reach adjusted p < 0.05: the adjusted p is a Benjamini–Hochberg correction over only the returned terms, confirmed on 1,077 rows from Enrichr itself (whether intentional is an open question for the maintainers). The Enrichr p-values are therefore reported as exploratory, not as significant findings; the local route is the method, and each term carries an exact specificity value — the hypergeometric tail, equal to the unadjusted one-sided Fisher p-value: a guard against generic terms, not a significance test. For the lipid panel the local route returns no significant term (best raw p 0.0019, adjusted p ≈ 1): the panel's support is at the gene level — ABCA1 with strong experimental evidence. The 19 Enrichr terms reduce to 3 groups, each sustained by a single gene (ABCA1, SCN1A, KPNA3): gene annotation, not pathway enrichment. The 19 specificity values are reported as numbers in `docs/validation/`; they are unadjusted p-values, so no term is labelled "specific". The cancer panel's three terms have specificity 0.61%, 0.32% and 0.48% (full tables in `docs/validation/`).

Positive controls: the strong-target lists of eight miRNAs from the official miRTarBase 9.0 index recover their expected biology in 6 of 8 cases (miR-155 and miR-34a are partial, their lists dominated by cancer genes). TargetScan recovers 54% of known strong targets (404 of 754): it predicts conserved sites only, and the miRTarBase intersection adds the validated targets it misses. Both are computational validations: KENRYU generates hypotheses and organizes evidence; neither substitutes for experimental validation. An offline test suite (237 tests, including the exact reproduction of the five-gene panel result) and continuous integration cover the software, archived on Zenodo (DOI 10.5281/zenodo.20564689).

# Software design
KENRYU is layered so the science does not depend on the network. The data layer holds TargetScan v8 predictions, the official miRTarBase 9.0 index (strong/weak evidence with PMIDs) and enrichment libraries (KEGG, Reactome, WikiPathways, GO); the repository ships without the large data files, while the hosted service keeps them. The core (`kenryu_core.py`) is pure functions — consensus (Strict / N-1 / N-2), Fisher enrichment with Benjamini–Hochberg correction, and the validation score — with no network access. The service layer (FastAPI app and CLI) shares that engine; an offline mode runs the whole pipeline locally, and the live layers (PubMed, ClinVar, ClinicalTrials.gov, Enrichr) never change the consensus genes. The suite has 237 offline tests; CI runs tests, a secret scan and a clean-clone install smoke test. Releases follow semantic versioning, cut only at milestones (`RELEASING.md`).

# Research impact statement
KENRYU was built for the author's master's thesis in bioinformatics (UNIR, 2026): the lipid-panel analysis and a second, independent cancer case study. It gives a researcher with a miRNA panel a one-command, offline analysis with every gene's evidence attached, instead of a bare target list to stitch together by hand. The validation is published in the repository's `docs/validation/`. External adoption is not claimed: colleagues are testing the software, and their use is the evidence the resubmission still needs.

# Summary
KENRYU is an open-source platform for the convergent analysis of microRNA (miRNA) target genes. Given a panel of miRNAs, it identifies the genes regulated by all — or nearly all — of them, combining thermodynamic target predictions from TargetScanHuman v8.0 [@lewis2005conserved; @mcgeary2019targeting], served locally, with post-hoc validation of each convergent gene against experimentally validated interactions from miRTarBase [@huang2022mirtarbase] and clinical databases (miRTarBase also serves as a fallback when TargetScan has no data for a miRNA). Three consensus modes (Strict, N-1, N-2) let the user trade sensitivity against confidence. Each convergent gene is then annotated with functional enrichment (KEGG, Reactome, WikiPathways, and Gene Ontology Biological Process), computed locally against the TargetScan universe with a live Enrichr [@kuleshov2016enrichr] cross-check, and with parallel evidence from PubMed, OMIM, ClinVar, and ClinicalTrials.gov [@sayers2022ncbi]. Results are shown as Venn diagrams, volcano plots, and a protein–protein interactome, and exported as a paginated academic report with a Vancouver-style bibliography. KENRYU is a FastAPI service with a web interface, containerized with Docker and deployed on Hugging Face Spaces, with a local database of 285 miRNA families and 13,035 human target genes. It is research-use-only software: it generates hypotheses and organizes evidence, and it does not provide clinical or diagnostic recommendations.

# Statement of need
miRNA target analysis is fragmented in practice: prediction and experimental validation live in separate tools, enrichment in another, and literature and clinical-trial evidence in yet others. A researcher studying a miRNA panel must therefore stitch together several resources by hand to answer one question — which genes does this panel converge on, and what is known about them? Existing tools typically export tables or isolated visualizations, or sum predictions from many predictors. KENRYU instead builds its consensus on TargetScan predictions and checks each convergent gene against miRTarBase and clinical databases in a validation dossier, then integrates enrichment, literature, and clinical-trial evidence into a single report, so every gene arrives with its evidence attached — and the reader can see which genes have experimental support and which are prediction-only.

# State of the field
Several established tools cover parts of this workflow; none covers the whole panel-to-report path. multiMiR [@ru2014multimir] is a Bioconductor R package with no web interface, no consensus modes, and no report generation.

| Tool | Input | Core computation | Evidence per gene | Runs where |
|---|---|---|---|---|
| miRPathDB 2027 [@flotho2026mirpathdb] | one miRNA or one pathway | precomputed miRNA–pathway associations; 3 evidence tiers (miRTarBase 9.0 + TarBase v9 experimental; TargetScan v8 + miRDB v6.0 predicted); 4 species | tier per association | web database |
| miRNet [@fan2016mirnet] | miRNA/gene list | integrates 11 miRNA databases; network visualisation + functional analysis | network edges | web only |
| miRWalk 3.0 [@sticht2018mirwalk] | miRNA/gene | TarPmiR random-forest scan of 5′UTR/CDS/3′UTR + TargetScan/miRDB/miRTarBase | target lists | web form |
| DIANA-miRPath v3 [@vlachos2015diana] | miRNA list | pathway analysis (KEGG/GO) from microT-CDS + TarBase | pathway level | web |
| miEAA 2023 [@aparicio2023mieaa] | miRNA list (mature/precursor, 10 species) | ORA + GSEA-like enrichment over 139,399 miRNA sets (19 repositories); API + Python package | miRNA-set membership | web / API / package |
| **KENRYU** | **miRNA panel** | **TargetScan convergence (Strict/N-1/N-2) + miRTarBase evidence tiers + per-gene literature/clinical dossier + calibrated local enrichment + bilingual report** | **strong/weak/none per gene, with PMIDs** | **local/offline or hosted** |

miRPathDB and miEAA enrich a miRNA or a miRNA list; KENRYU enriches the convergent target genes of a panel and attaches the evidence for each gene — the gap between a target predictor and a finished, evidence-backed report, runnable locally or as a hosted service.

# Validation and use
KENRYU was validated on a five-miRNA lipid panel (hsa-miR-33a-5p, hsa-miR-33b-5p, hsa-miR-144-3p, hsa-miR-758-3p, hsa-miR-106b-5p). In Strict mode it recovered the known miR-33 → ABCA1 axis and returned five convergent genes — ABCA1, KPNA3, SCN1A, SNTB2, and TSC22D2. This analysis is part of the author's master's thesis in bioinformatics (Universidad Internacional de La Rioja, 2026). A second, independent case study used a cancer panel never tried before (hsa-miR-21-5p, hsa-miR-155-5p, hsa-let-7a-5p): run live against the deployed service, Strict mode returned 18 convergent genes — AAK1, ACVR2A, AGO4, BNC2, BRWD3, CHD7, DCUN1D3, FOXP1, IL6R, KPNA4, MEIS1, PURB, RDX, RPS6KA3, SESN3, UBN2, WNK3, XKR4 — with three Enrichr terms (Developmental Biology, Reactome, p-adj 0.0176; Recycling Pathway of L1, 0.0424; Signaling by TGFBR3, 0.0424), a biologically coherent result (AGO4 is a RISC component; ACVR2A sits in the TGF-beta pathway). Re-run live with v1.54, the panel returns the same 18 genes, levels and terms. The full case study is documented in `docs/case-study-cancer-panel.md`.

The enrichment method is the calibrated local Fisher test with the TargetScan universe as background, not the live Enrichr route. A random-panel protocol (`validate_random_panels.py`; 300 N-1 panels of 5 miRNAs, 300 Strict panels of 2 miRNAs, 65 thesis-sized panels; seeds 7, 11, 3) measures the false-positive rate — the fraction of random panels with at least one significant term (adjusted p < 0.05). With the TargetScan universe the local rate is 7.3% (GO), 11.7% (Reactome) and 3.3% (WikiPathways) for N-1 panels, 17.0%, 12.7% and 7.3% for Strict 2-miRNA panels, and 1.5%, 3.1% and 0% for thesis-sized panels — above 5% for larger lists, because miRNA targets concentrate in regulatory genes, and near zero for panels of 4–6 genes. The same protocol run against the live Enrichr route (`calibrate_enrichr.py`; 100 random 5-gene lists, libraries GO Biological Process 2023, Reactome Pathways 2024, WikiPathways 2019 Human and KEGG 2021 Human, checked 2026-11-19) gives a false-positive rate of 98% (GO), 75% (Reactome), 86% (WikiPathways) and 56% (KEGG): no random list at all came back without a "significant" term, and single-gene overlaps already reach adjusted p < 0.05. The Enrichr p-values in the two case studies are therefore reported as exploratory, not as significant findings; the local route is the method, and each term carries a specificity value — the fraction of random gene lists of the same size in which the term appears by chance. For the lipid panel the local route returns no significant term at all (best raw p 0.0019, adjusted p ≈ 1 after correction over ~8,000 terms): the panel's support is at the gene level — ABCA1 with strong experimental evidence — and its enrichment is exploratory. Of the 19 lipid-panel terms, 12 are specific (below 0.03) and 7 are near the threshold (0.03–0.07), reported as numbers only: Selenium Micronutrient Network 0.0576, Folate Metabolism 0.0491, Rett syndrome causing genes 0.0465, Cholesterol metabolism 0.0350, Vitamin B12 Metabolism 0.0339, Import Into Nucleus 0.0311, ABC transporters 0.0309. The cancer panel's three terms have specificity <1%, <1% and 0.01. Full tables are in `docs/validation/`.

Positive controls use strong-evidence targets: the strong-target lists of eight miRNAs from the official miRTarBase 9.0 index, run through the local enrichment, recover their expected biology in 6 of 8 cases (lipid metabolism for miR-33a, apoptosis for miR-21, extracellular-matrix organisation for miR-29a); miR-155 and miR-34a are partial, their lists dominated by cancer genes from the validation literature. TargetScan recovers 54% of known strong targets (404 of 754): it predicts conserved sites only, and the miRTarBase intersection adds the validated targets it misses. Both cases are computational validations: KENRYU generates hypotheses and organizes evidence, and neither substitutes for experimental validation. The software is covered by an offline test suite (215 tests, including the exact reproduction of the five-gene panel result) and continuous integration, and it is archived on Zenodo (DOI 10.5281/zenodo.20564689).

# Software design
KENRYU is layered so the science does not depend on the network. The data layer holds TargetScan v8 predictions, the official miRTarBase 9.0 index (strong/weak evidence with PMIDs) and enrichment libraries (KEGG, Reactome, WikiPathways, GO), downloaded from their official pages: the repository ships without the large data files, while the hosted service keeps them. The core (`kenryu_core.py`) is pure functions — consensus (Strict / N-1 / N-2), Fisher enrichment with Benjamini–Hochberg correction, and the validation score — with no network access. The service layer (FastAPI app and CLI) shares that engine; an offline mode runs the whole pipeline locally, and the live layers (PubMed, ClinVar, ClinicalTrials.gov, Enrichr) never change the consensus genes. The suite has 215 offline tests; CI runs tests, a secret scan and a clean-clone install smoke test. Releases follow semantic versioning, cut only at milestones (`RELEASING.md`).

# Research impact statement
KENRYU was built for the author's master's thesis in bioinformatics (UNIR, 2026), where it produced the lipid-panel analysis (miR-33 → ABCA1 axis, five convergent genes) and a second, independent cancer case study. It gives a researcher with a miRNA panel a one-command, offline analysis whose every gene arrives with its evidence attached, instead of a bare target list to stitch together by hand. The validation (random-panel calibration, per-term specificity, strong-evidence positive controls, TargetScan sensitivity) is published in the repository's `docs/validation/`. External adoption is not claimed: the software is being tested by colleagues, and their use is the evidence the resubmission still needs.

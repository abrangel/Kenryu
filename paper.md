# Summary
KENRYU is an open-source platform for the convergent analysis of microRNA (miRNA) target genes. Given a panel of miRNAs, it identifies the genes regulated by all — or nearly all — of them, combining thermodynamic target predictions from TargetScanHuman v8.0 [@lewis2005conserved; @mcgeary2019targeting], served locally, with post-hoc validation of each convergent gene against experimentally validated interactions from miRTarBase [@huang2022mirtarbase] and clinical databases (miRTarBase also serves as a fallback when TargetScan has no data for a miRNA). Three consensus modes (Strict, N-1, N-2) let the user trade sensitivity against confidence. Each convergent gene is then annotated with functional enrichment (KEGG, Reactome, WikiPathways, and Gene Ontology Biological Process, via Enrichr [@kuleshov2016enrichr]) and with parallel evidence from PubMed, OMIM, ClinVar, and ClinicalTrials.gov [@sayers2022ncbi]. Results are shown as Venn diagrams, volcano plots, and a protein–protein interactome, and exported as a paginated academic report with a Vancouver-style bibliography. KENRYU is a FastAPI service with a web interface, containerized with Docker and deployed on Hugging Face Spaces, with a local database of 285 miRNA families and 13,035 human target genes. It is research-use-only software: it generates hypotheses and organizes evidence, and it does not provide clinical or diagnostic recommendations.

# Statement of need
miRNA target analysis is fragmented in practice: prediction and experimental validation live in separate tools, enrichment in another, and literature and clinical-trial evidence in yet others. A researcher studying a miRNA panel must therefore stitch together several resources by hand to answer one question — which genes does this panel converge on, and what is known about them? Existing tools typically export tables or isolated visualizations, or sum predictions from many predictors. KENRYU instead builds its consensus on TargetScan predictions and then checks each convergent gene against miRTarBase and clinical databases in a validation dossier, so every gene arrives with its evidence attached — and the reader can see which genes have experimental support and which are prediction-only. It then integrates enrichment, literature, and clinical-trial evidence into a single report, so the convergent genes arrive with their evidence attached instead of as a bare list.

# State of the field
Several established tools cover parts of this workflow, and KENRYU differs from each of them in one specific respect. multiMiR [@ru2014multimir] is a Bioconductor R package that integrates validated (miRecords, miRTarBase, TarBase) and predicted (DIANA-microT, ElMMo, MicroCosm, miRanda, miRDB, PicTar, PITA, TargetScan) miRNA–target databases with miRNA–disease and miRNA–drug associations; it is a programming library, with no web interface, no consensus modes, and no report generation. miRWalk 3.0 [@sticht2018mirwalk] is a web resource that scans 5′UTR, CDS, and 3′UTR with a random-forest model (TarPmiR) and integrates TargetScan, miRDB, and miRTarBase; it returns target lists from a web form, with no Strict / N-1 / N-2 convergence modes, no per-gene literature and clinical-trial dossier, and no local execution. DIANA-miRPath v3 [@vlachos2015diana] performs pathway analysis (KEGG and Gene Ontology) from microT-CDS predicted and TarBase validated targets; it works at pathway level, with no convergent-gene report and no PubMed, OMIM, ClinVar, or ClinicalTrials.gov evidence attached to each gene. miRNet [@fan2016mirnet] is a web tool that integrates 11 miRNA databases with network visualization and functional analysis; it is network-centred and web-only, with no Strict / N-1 / N-2 convergence consensus and no bilingual report export. Earlier tools such as funcExplorer, SMiRK, CAP-miRSeq, and miRViz provide clustering, enrichment, or visualization, but each covers only part of the workflow and none builds its convergence on TargetScan predictions with a per-gene validation dossier. Broad multi-omics platforms (e.g. PandaOmics, BioJupies) address wider questions and do not focus on miRNA panel convergence. KENRYU fills the gap between a target predictor and a finished, evidence-backed report for a miRNA panel: TargetScan-based convergence, multi-source evidence per gene, and an exportable bilingual report, runnable locally or as a hosted service.

# Validation and use
KENRYU was validated on a five-miRNA lipid panel (hsa-miR-33a-5p, hsa-miR-33b-5p, hsa-miR-144-3p, hsa-miR-758-3p, hsa-miR-106b-5p). In Strict mode it recovered the known miR-33 → ABCA1 axis and returned five convergent genes — ABCA1, KPNA3, SCN1A, SNTB2, and TSC22D2 — with significant enrichment in lipid and cholesterol pathways. This analysis is part of the author's master's thesis in bioinformatics (Universidad Internacional de La Rioja, 2026). A second, independent case study used a cancer panel never tried before (hsa-miR-21-5p, hsa-miR-155-5p, hsa-let-7a-5p): run live against the deployed service on 2026-11-11, Strict mode returned 18 convergent genes — AAK1, ACVR2A, AGO4, BNC2, BRWD3, CHD7, DCUN1D3, FOXP1, IL6R, KPNA4, MEIS1, PURB, RDX, RPS6KA3, SESN3, UBN2, WNK3, XKR4 — with three significant enrichment terms (Developmental Biology, Reactome, p-adj 0.0176; Recycling Pathway of L1, 0.0424; Signaling by TGFBR3, 0.0424), a biologically coherent result (AGO4 is a RISC component; ACVR2A sits in the TGF-beta pathway). Re-run live with v1.54 on 2026-11-19, the panel returns the same 18 genes, the same levels (AGO4 and MEIS1 "high" with strong evidence; CHD7 "medium" since v1.53, when "high" started requiring strong evidence) and the same three terms with the same adjusted p-values. The full case study is documented in `docs/case-study-cancer-panel.md`. Both cases are computational validations: KENRYU generates hypotheses and organizes evidence, and neither substitutes for experimental validation. The software is covered by an offline test suite (206 tests, including the exact reproduction of the five-gene panel result) and continuous integration, and it is archived on Zenodo (DOI 10.5281/zenodo.20564689).

Panel-level calibration. A random-panel protocol (`validate_random_panels.py`, 300 random 5-miRNA panels in N-1 mode, 300 random 2-miRNA panels in Strict mode, and 65 thesis-sized panels of 4–6 genes; seeds 7, 11 and 3) measures the false-positive rate of the enrichment step — the fraction of random panels with at least one significant term (adjusted p < 0.05). With the library-union background the rate was 13.3% (GO), 16.3% (Reactome) and 5.7% (WikiPathways) for N-1 panels and 28.7%, 20.0% and 12.7% for Strict 2-miRNA panels — 2–6× the 5% a calibrated method should give. With the TargetScan universe as background (v1.54) the rates fall to 7.3%, 11.7% and 3.3% (N-1) and 17.0%, 12.7% and 7.3% (Strict) — still above 5% for GO and Reactome, because miRNA targets concentrate in regulatory genes, so terms such as regulation of transcription appear in almost any panel. The panel-union background used before v1.54 was more conservative still (2.3%, 4.7% and 1.0% for N-1 panels; 2.0%, 4.0% and 1.3% for Strict 2-miRNA panels) but had almost no power: it returned zero terms for the 188-gene N-1 cancer panel, against 43 with the TargetScan universe. For thesis-sized panels (4–6 genes) there is no inflation: 3.1%, 3.1% and 0% with the library union, 1.5%, 3.1% and 0% with the TargetScan universe. Each enrichment term now carries a specificity value: the fraction of 100 random panels of the same size in which the term appears by chance (1.0 = generic, 0.0 = specific). The cancer case study's three terms have specificity 0.0, 0.0 and 0.01. Positive controls (miR-17, let-7 and miR-34 families) were weak and are not presented as validation: they use predicted, not demonstrated, targets.
